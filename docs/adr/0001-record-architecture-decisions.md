# 1. Record architecture decisions

Date: 2026-09-19 · Status: accepted

## Context

The project was rebuilt from a coding-test prototype into a reference NestJS application.
Choices that are not obvious from the code need a home.

## Decision

Keep lightweight ADRs in `docs/adr/`, numbered, one decision per file, in the
context / decision / consequences format.

## Consequences

Reviewers can question a decision instead of reverse-engineering it; superseded decisions are
marked, not deleted.
